# Little Things in the Woods — Privacy Policy

*Last updated: October 15, 2026*

Little Things in the Woods ("the game") is an offline Android game.

**The game collects no data.** It has no accounts, no ads and no analytics, and it asks for no permissions at all — not even the internet — so it cannot send anything anywhere.

**What stays on your phone.** The game remembers how far you are in each story (including where things are hidden this time), which stories you have finished, and whether the sound is on. This is kept in the game's own storage on your device, never leaves it, and is removed when you uninstall the game (or clear its data in Android's settings).

**Children.** The game is not directed at children.

**Changes.** If this policy changes, the new version will be posted on this page.

# 林间小事 — 隐私政策

*最近更新：2026 年 10 月 15 日*

《林间小事》（下称“本游戏”）是一个离线的安卓游戏。

# 森のちいさなできごと — プライバシーポリシー

*最終更新日：2026年10月15日*

「森のちいさなできごと」（以下「本ゲーム」）は、オフラインで動く Android ゲームです。

**本ゲームはデータを一切収集しません。** アカウント、広告、アクセス解析はありません。権限も一切求めず、インターネットの権限もないため、どこにも何も送信できません。

**端末に残るもの。** 本ゲームは、各お話の進み具合（今回ものが隠れている場所を含む）、クリアしたお話、サウンドのオン・オフを記録します。これらは端末内の本ゲーム専用の保存領域にだけ保存され、端末の外に出ることはなく、アンインストール（または Android の設定でデータを消去）すると削除されます。

**子どもについて。** 本ゲームは子どもを対象としていません。

**変更。** 本ポリシーを変更する場合は、新しい内容をこのページに掲載します。

**お問い合わせ。** sublueai@gmail.com
